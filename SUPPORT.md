# Support

This is a noncommercial archive project with one maintainer. It provides server source, not a client or a hosted server.

| Need | Where |
|---|---|
| A defect in the server | 🐛 [Open a defect](https://github.com/l2go/l2jfree/issues/new/choose) |
| A feature or an improvement | ✨ [Open a feature request](https://github.com/l2go/l2jfree/issues/new/choose) |
| A design question | 🧭 Read the [decision records](docs/adr/README.md), then open a decision proposal |
| A vulnerability | 🛡️ [Private advisory](SECURITY.md) |
| How the project is run | [README](README.md) and the [documentation index](docs/index.md) |

There is no support for the 2.x line.
